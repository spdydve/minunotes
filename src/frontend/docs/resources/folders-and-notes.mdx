# Folders and notes

Folders provide the main hierarchy in MinuNotes. Notes hold the actual content, while subfolders let a larger area grow without flattening everything into one list.

## Choose a simple structure

Start with a few durable areas rather than a folder for every topic:

```txt
Projects/
Research/
Meetings/
Archive/
```

Add subfolders only when a folder becomes difficult to scan.

## Create content

Select a folder, then create a note or subfolder from its available actions. A note belongs to one folder at a time and can be moved later.

Use clear note titles. Titles power navigation, search results, and wikilink suggestions.

## Move and rename

Use the note or folder actions to rename or move content. Moving a folder moves its descendants with it.

Before reorganizing a shared folder, consider how the change affects collaborators who rely on its hierarchy.

## Folders versus tags and links

- **Folders** answer “Where does this belong?”
- **Tags** answer “What theme or status does this have?”
- **Wikilinks** answer “What other idea is this connected to?”

Using all three lightly is usually more useful than building a very deep folder tree.
