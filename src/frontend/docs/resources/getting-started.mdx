# Getting started

MinuNotes is a focused workspace for writing, connecting, and sharing Markdown notes. This guide takes you from an empty workspace to a small, useful collection of connected notes.

## 1. Create a folder

Use **New folder** in the sidebar and give it a name that describes an area of work, such as `Projects`, `Research`, or `Personal`.

Folders can contain notes and subfolders. Start broad; you can add more structure when you need it.

## 2. Create your first note

Open the folder and choose **New note**. Give the note a specific title, then begin typing.

MinuNotes saves changes automatically. You do not need to manage a separate save step.

## 3. Add structure while you write

Use Markdown directly or type `/` on an empty line to insert a heading, list, task list, table, image, code block, or other common block.

Try this simple structure:

```md
# Project brief

## Goal

Describe the outcome.

## Next actions

- [ ] First action
- [ ] Second action
```

Learn more in [Markdown and editor](/resources/markdown-editor) and [Slash commands](/resources/slash-commands).

## 4. Connect related notes

Type `[[` and choose another note to create a wikilink. The linked note will show a backlink to the note you are writing.

Use folders for hierarchy, wikilinks for relationships, and tags for themes that cross folder boundaries.

## 5. Find your work

Press `Cmd/Ctrl+K` to search notes and folders. Search is often faster than navigating a deep folder tree.

## 6. Share when you are ready

Open a note or folder's share controls to invite a person as a Viewer, Commenter, or Editor. Use a public link only when anonymous, read-only access is appropriate.

Read [Share notes and folders](/resources/sharing-and-collaboration) before sharing sensitive material.
