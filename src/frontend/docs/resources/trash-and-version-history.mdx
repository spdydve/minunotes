# Trash and version history

Trash protects against accidental deletion, while version history lets you inspect and restore earlier states of an individual note.

## Move content to Trash

Deleting a note or folder moves it to Trash instead of immediately removing it forever. Trashed folders keep their descendants together.

Open **Trash** from the app navigation to review deleted content.

## Restore or permanently delete

Restore an item when you need it back in the workspace. Permanent deletion cannot be undone, so use it only after confirming the content is no longer required.

Ownership and collaboration rules continue to apply in Trash. General restore and permanent-deletion actions are owner-controlled.

## Review version history

Open a note's actions and choose **Version history** to inspect saved snapshots. Select a version to preview its title and content.

## Restore a version

Restore the selected snapshot to make it the note's current state. MinuNotes preserves a snapshot before restoration so the newer state is not silently lost.

Version history is for recovering earlier note content; it does not replace Trash for deleted notes or folders.

## Safer editing

For important changes, use clear note titles and review the current note before replacing large sections. Agent integrations use content hashes to prevent stale edits from overwriting newer work.
