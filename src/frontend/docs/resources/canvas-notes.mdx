# Canvas notes

Canvas notes provide a visual surface for arranging ideas, relationships, and flows. Mind-map notes use the same canvas foundation with a more structured layout.

## When to use a canvas

A canvas works well for:

- Brainstorms and early research
- Concept maps
- Project flows
- Collections of related notes
- Presenting a system at a glance

Use a Markdown note when reading order and detailed prose matter more than spatial arrangement.

## Work with nodes

Add nodes, edit their text, and arrange them on the canvas. Connect nodes to show a relationship or direction.

Canvas changes save as part of the note. Use the canvas controls to zoom and navigate larger diagrams.

## Link a node to a note

Select a node, open its context menu, and choose **Link to note…**. A linked node shows a note badge that opens the target note.

A node can retain an external web URL separately from its internal MinuNotes note link.

## Backlinks and graph context

Internal canvas note links are indexed with Markdown links. The target note can therefore show the canvas in its backlinks.

## Agent editing

Agent integrations can read and update canvas JSON or generate a complete canvas from Minu diagram syntax. Access checks still apply to every linked note.

Read [Wikilinks and backlinks](/resources/wikilinks-backlinks) or [Agent integrations](/resources/agent-integrations) for the next step.
