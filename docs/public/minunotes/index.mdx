MinuNotes is a focused workspace for writing, connecting, and sharing Markdown notes. It combines straightforward organization with collaboration, visual canvases, and carefully scoped agent integrations.

## Start here

New to MinuNotes? Follow [Getting started](/resources/getting-started) to create a folder and note, connect ideas, find your work, and choose what to explore next.

## Learn MinuNotes

- **Write:** Markdown, slash commands, images, and canvas notes.
- **Organize:** Folders, wikilinks, backlinks, tags, and search.
- **Collaborate:** Invitations, public links, comments, and Review.
- **Protect and recover:** Permission boundaries, Trash, and version history.

## Build with MinuNotes

Connect trusted agents and developer tools through scoped API keys, OAuth, MCP, OpenAPI, and the Harness API. Start with [Agent integrations](/resources/agent-integrations).
