Review comments keep discussion anchored to the text it concerns. Use them for questions, suggestions, approvals, and follow-up work without placing the conversation inside the note body.

## Start a discussion

Select text in an editable or reviewable Markdown note and choose the comment action. Enter a plain-text message to create a thread anchored to that selection.

The Review panel shows open discussions and their location in the note.

## Reply and react

Open a thread to add a reply. Reactions are useful for lightweight acknowledgement when a full reply is unnecessary.

Comment messages are plain text so discussions stay predictable across the app and agent integrations.

## Resolve completed work

Resolve a thread when the question or requested change is complete. Resolved threads can be reopened if the discussion needs to continue.

## When text changes

MinuNotes maps anchors as the note changes. If the original text can no longer be mapped safely, the discussion may appear detached rather than being attached to the wrong content.

## Permission required

Owners and eligible editors can comment. A collaborator with the Commenter role can participate without receiving general edit access. Connected agents need explicit Comment permission in the relevant scope.
